# تمرین اول جاوا اسکریپت - تغییر متن (DOM Manipulation)

این پروژه یک تمرین ساده برای یادگیری دستکاری DOM (Document Object Model) در جاوا اسکریپت است.

## 📝 ویژگی‌ها
- تغییر متن یک تگ `h1` با کلیک روی دکمه
- تغییر رنگ متن به صورت داینامیک با استفاده از جاوا اسکریپت
- طراحی ساده و تمیز با استفاده از CSS (Flexbox)

## 🛠 تکنولوژی‌های استفاده شده
- HTML5
- CSS3
- Vanilla JavaScript

## 🚀 نحوه اجرا
برای اجرای این پروژه، کافیست فایل `index.html` را در مرورگر خود باز کنید.
